# Interactive Map Prototype

A web-based interactive map prototype developed using HTML, CSS and JavaScript. The project allows users to enter a starting location and destination, generate a route, and view navigation information such as total distance, number of turns and distance to the next turn.

### Features

* Interactive map using Leaflet.js
* Location search using OpenStreetMap Nominatim API
* Route generation using Leaflet Routing Machine
* Distance calculation
* Turn count and next-turn information
* Speed monitoring interface

### Technologies

* HTML
* CSS
* JavaScript
* Leaflet.js
* OpenStreetMap
* Nominatim API
* Leaflet Routing Machine

### Project Purpose

Created as a navigation prototype to explore interactive maps, location-based services, routing and real-time navigation interfaces.
